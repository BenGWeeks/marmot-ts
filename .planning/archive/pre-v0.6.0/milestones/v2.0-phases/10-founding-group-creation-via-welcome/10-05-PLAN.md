is a safe, well-defined operation"). Per the user's 2026-09-28 locked decision, this **reverses D-09**: a founding
create with invitees and no valid group relays now fails closed, before any MLS state exists, instead of silently
producing a persisted group with N phantom members whose Welcomes all fail.

non-empty relays tag"). The group has no `transport.nostr.routing` component so it can never publish the commit
that would add relays — a permanent dead group. Two in-source JSDoc blocks still describe the disproven NIP-65
inbox fallback, and `founding-create.test.ts` Test 13 pins the defect as expected behaviour.

`marmot-group.ts`, a rewritten Test 13 plus a new Test 15 guarding the still-allowed solo relay-less create, the
corrected docs bullet, and a D-09/R-05 supersession record in `10-CONTEXT.md`.
